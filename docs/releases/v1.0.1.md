# OfficeFlow 1.0.1

This release adds first-run usernames, password hints, one-time recovery codes,
and the refreshed OfficeFlow interface to the Windows installer. The demo and
installed app share the updated UI. A new workspace starts with **Create
account**; an existing workspace continues at **Log in** with its saved accounts.

## First start and upgrades

On a new workspace, choose a username, a 6–12 character password, and a hint
that does not contain the complete username or password. Save the recovery code
shown once, away from this computer. The code can reset a forgotten username or
password and rotates after use. If OfficeFlow opens at **Log in**, it found an
existing workspace; an upgrade does not erase accounts or records. Older
accounts can continue using their existing credentials.

The workspace is stored at `%LOCALAPPDATA%\OfficeFlow\officeflow.mv.db` and is
kept on reinstall and uninstall. Back it up before changing or removing data.

## Windows 11 Smart App Control

This installer and launcher are unsigned. Smart App Control may block the
installer, app, or uninstaller even when installation succeeded. GitHub hosting
and SHA-256 checksums do not make an unsigned executable trusted. There is no
per-app exception. Turning Smart App Control off is your choice and also removes
its protection against other untrusted apps. Depending on your Windows version,
turning it back on may require a Windows reset. Read [Microsoft's Smart App
Control FAQ](https://support.microsoft.com/en-gb/windows/security/threat-malware-protection/smart-app-control-frequently-asked-questions)
before changing the setting. Reliable operation with Smart App Control On
requires trusted code signing and a clean Windows 11 install and launch test.
