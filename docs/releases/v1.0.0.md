# OfficeFlow 1.0.0 (draft release notes)

The first release of OfficeFlow: an inventory and requisition app for one shared
computer. Download one installer, run it, and open OfficeFlow from the Start
menu. Java is included; nothing else needs to be installed first. To look
around first, try the [live demo with sample data](https://devbyabir.github.io/officeflow/).

## Download

| File | Purpose |
| --- | --- |
| `OfficeFlow-Setup-1.0.0-x64.exe` | The Windows x64 installer, with OfficeFlow's own Java runtime |
| `OfficeFlow-Setup-1.0.0-x64.exe.sha256` | SHA-256 checksum of the installer |
| `OfficeFlow-1.0.0-TERMS.md` | The OfficeFlow end-user terms for this release. Please read them before downloading |
| `OfficeFlow-1.0.0-java-runtime-source.zip` (and `.sha256`, `-PROVENANCE.md`) | Source code of the bundled Eclipse Temurin runtime (GPLv2 with Classpath Exception) and how the runtime was built |

To check the download in PowerShell, compare the output of
`Get-FileHash .\OfficeFlow-Setup-1.0.0-x64.exe` with the `.sha256` file.

## Requirements

- Windows 10 or 11, 64-bit (x64).
- The Microsoft Visual C++ Redistributable for Visual Studio 2015-2022 (x64),
  14.40 or newer. Most PCs already have it. If it is missing, setup offers to
  download Microsoft's official installer from Microsoft and run it; Windows
  asks for administrator permission for that step only.
- A web browser.

## Install and start

1. Run `OfficeFlow-Setup-1.0.0-x64.exe`. It installs for your Windows account
   into `%LOCALAPPDATA%\Programs\OfficeFlow`, without administrator rights.
2. Open **OfficeFlow** from the Start menu.
3. First start only: choose the administrator password (12–120 characters;
   typing is hidden). OfficeFlow opens **http://127.0.0.1:8080**; sign in as `001`.

Keep the OfficeFlow window open while you use it. Stop it with `Ctrl+C` or by
closing the window.

## Your data

The workspace is one file, `%LOCALAPPDATA%\OfficeFlow\officeflow.mv.db`, outside
the program folder; `officeflow.log` beside it records starts and clean stops.
Installing a newer version and uninstalling both keep it. To update, stop
OfficeFlow and run the newer setup (setup asks you to close OfficeFlow if it is
running). Back up by copying the file while OfficeFlow is stopped.

If you ran OfficeFlow from source before and your database is in a `data` folder
in the checkout, see "Upgrading from an earlier version" in the README.

## Highlights

- Supplies, teachers and requisitions with stock reservations: pending requests
  reserve stock, issuing deducts it once, and rejecting or cancelling releases it.
- Administrator and teacher accounts. New teachers get a one-time temporary
  password and choose their own at first sign-in.
- CSV import with rollback, and CSV reports.
- Clear startup messages for a busy port, a workspace already open, or missing files.

## Known limitations

- One computer only: other computers on the network cannot connect.
- The installer is for Windows x64; on macOS or Linux, run from source.

## How this release was checked

Built by the "Windows installer" workflow on a Windows Server 2025 runner: the
installer is installed per user, OfficeFlow is started from its Start menu
shortcut, an inventory item is saved, OfficeFlow is stopped with Ctrl+C (clean
stop recorded in `officeflow.log`) and restarted with the item still there; an
upgrade is refused while OfficeFlow runs, then an upgrade to a test build keeps
the workspace file byte-for-byte; uninstalling keeps the workspace.
