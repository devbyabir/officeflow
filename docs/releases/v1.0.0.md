# OfficeFlow 1.0.0

The first release of OfficeFlow: an inventory and requisition app for one shared
computer. Download one installer, run it, and open OfficeFlow from the Start
menu. Java is included; nothing else needs to be installed first. To look
around first, try the [live demo with sample data](https://devbyabir.github.io/officeflow/).

## Requirements

- Windows 10 or 11, 64-bit (x64).
- The Microsoft Visual C++ Redistributable for Visual Studio 2015-2022 (x64),
  14.40 or newer. Most PCs already have it. If it is missing, setup offers to
  download Microsoft's official installer from Microsoft and run it; Windows
  asks for administrator permission for that step only.
- A web browser.

## Install and start

1. Run `OfficeFlow-Setup-1.0.0-x64.exe`. It installs for your Windows account
   into `%LOCALAPPDATA%\Programs\OfficeFlow`, without administrator rights.
2. Open **OfficeFlow** from the Start menu. It starts in the background, with no
   window, and opens **http://127.0.0.1:8080** in your browser.
3. First start only: the **Create account** screen asks for a username and a
   password for the administrator. It works only on this computer, for 15
   minutes, and once; then you are logged in. Later, **Log in** with that username.

Stop OfficeFlow with **Quit OfficeFlow** (in the sidebar, on the sign-in screen,
or in the Start menu). Closing the browser tab leaves it running.

## Your data

The workspace is one file, `%LOCALAPPDATA%\OfficeFlow\officeflow.mv.db`, outside
the program folder; `officeflow.log` beside it records starts and clean stops.
Installing a newer version and uninstalling both keep it. To update, run the
newer setup; if OfficeFlow is open, setup stops it cleanly first. Back up by
copying the file while OfficeFlow is stopped.

If you ran OfficeFlow from source before and your database is in a `data` folder
in the checkout, see "Upgrading from an earlier version" in the README.

## Highlights

- Supplies, teachers and requisitions with stock reservations: pending requests
  reserve stock, issuing deducts it once, and rejecting or cancelling releases it.
- Administrator and teacher accounts. New teachers get a one-time temporary
  password and choose their own at first sign-in.
- CSV import with rollback, and CSV reports.
- Usernames: log in with a username, or with the account ID for accounts from
  before usernames (such as `001`). New passwords are passphrases of 15–120
  characters; existing passwords stay valid.
- A clearer inventory: the item name leads, its ID sits beneath it, and
  Available (on hand minus reserved) and On hand have their own columns.
- Clear startup messages for a busy port, a workspace already open, or missing files.

## Known limitations

- One computer only: other computers on the network cannot connect.
- The installer is for Windows x64; on macOS or Linux, run from source.

## How this release was checked

Built by the "Windows installer" workflow on a Windows Server 2025 runner: the
installer is installed per user; OfficeFlow is started from its Start menu
shortcut without any visible window, the administrator is created on the setup
screen, an inventory item is saved, and OfficeFlow is quit with the **Quit
OfficeFlow** shortcut (clean stop recorded in `officeflow.log`) and reopened with
the item still there. An upgrade to a test build while OfficeFlow runs stops it
cleanly first and keeps the account and item; a reinstall keeps the workspace
file byte-for-byte; uninstalling keeps the workspace.

**Still pending:** code signing, and a test of the exact signed installer on
Windows 11 with Smart App Control on, after a normal browser download.
The published 1.0.0 binaries are unsigned and may be blocked by Smart App
Control. GitHub hosting and checksums cannot verify a publisher.
