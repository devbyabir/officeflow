# OfficeFlow 1.0.0 (draft release notes)

The first release of OfficeFlow: an inventory and requisition app for one shared
computer. Download one ZIP, extract it, and start it with your installed Java.
No Maven and no build step are needed. To look around first, try the
[preview with sample data](https://devbyabir.github.io/officeflow/).

## Download

| File | Purpose |
| --- | --- |
| `OfficeFlow-1.0.0.zip` | The app: `officeflow.jar`, its web files, `Quick Start.txt` and the licence files |
| `OfficeFlow-1.0.0.zip.sha256` | SHA-256 checksum of the ZIP |
| `SHA256SUMS.txt` | The same checksum, in the usual list format |
| `OfficeFlow-1.0.0-TERMS.md` | The OfficeFlow end-user terms for this release. Please read them before downloading |

To check the download in PowerShell, compare the output of
`Get-FileHash .\OfficeFlow-1.0.0.zip` with the `.sha256` file.

## Requirements

- **Java 17 or newer**, installed (for example the Eclipse Temurin JRE from
  https://adoptium.net/). Check with `java -version`.
- A web browser. Windows, macOS or Linux.

## Run it

1. Extract the whole ZIP to a folder you keep and open a terminal there (on
   Windows: right-click the folder → **Open in Terminal**).
2. First start only, choose the administrator password (12–120 characters):

   ```powershell
   $env:OFFICEFLOW_ADMIN_PASSWORD = [Net.NetworkCredential]::new("", (Read-Host "New OfficeFlow admin password" -AsSecureString)).Password
   ```

3. Start OfficeFlow:

   ```powershell
   java -jar officeflow.jar
   ```

4. Open **http://127.0.0.1:8080** and sign in as `001`.

Stop OfficeFlow with `Ctrl+C` in its window. Later starts need only step 3.

## Your data

On Windows the workspace is one file, `%LOCALAPPDATA%\OfficeFlow\officeflow.mv.db`,
outside the extracted folder; `officeflow.log` beside it records starts and clean
stops. OfficeFlow prints the exact path when it starts. Updating means extracting
the new ZIP to a new folder: it opens the same workspace. Back up by copying the
file while OfficeFlow is stopped. On macOS and Linux the data is in the `data`
folder of the folder you start OfficeFlow from.

If you ran OfficeFlow from source before and your database is in a `data` folder
in the checkout, see "Upgrading from an earlier version" in the README.

## Highlights

- Supplies, teachers and requisitions with stock reservations: pending requests
  reserve stock, issuing deducts it once, and rejecting or cancelling releases it.
- Administrator and teacher accounts. New teachers get a one-time temporary
  password and choose their own at first sign-in.
- CSV import with rollback, and CSV reports.
- Clear startup messages for a busy port, a workspace already open, or missing files.

## Known limitations

- One computer only: other computers on the network cannot connect.
- Java must be installed separately.

installed Java 17, the test extracts the ZIP into a folder with spaces, runs
`java -jar officeflow.jar`, adds a record, stops with Ctrl+C (clean stop recorded
