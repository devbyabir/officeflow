# OfficeFlow 1.0.0 for Windows (draft release notes)

The first downloadable release of OfficeFlow: an inventory and requisition app
for one shared Windows PC. Download, extract and double-click. Java is included;
the only prerequisite is Microsoft's Visual C++ Redistributable (x64), which many
PCs already have.

## Download

| File | Purpose |
| --- | --- |
| `OfficeFlow-1.0.0-windows-x64.zip` | The app, with its own Java runtime (about 36 MB) |
| `OfficeFlow-1.0.0-windows-x64.zip.sha256` | SHA-256 checksum of the ZIP |
| `OfficeFlow-1.0.0-java-runtime-source.zip` | Complete corresponding source for the bundled Java runtime (not needed to run OfficeFlow) |
| `OfficeFlow-1.0.0-java-runtime-source.zip.sha256` | SHA-256 checksum of the source archive |
| `OfficeFlow-1.0.0-java-runtime-source-PROVENANCE.md` | Where the runtime and its source came from, and how they were verified |
| `SHA256SUMS.txt` | Checksums of both archives |
| `OfficeFlow-1.0.0-TERMS.md` | The OfficeFlow end-user terms for this release. Please read them before downloading |

To check the download in PowerShell, compare the output of
`Get-FileHash .\OfficeFlow-1.0.0-windows-x64.zip` with the `.sha256` file.

**Requirements:**

- Windows 10 or 11 (64-bit), Windows PowerShell (built into Windows) and a web
  browser.
- **Microsoft Visual C++ Redistributable for Visual Studio 2015-2022 (x64),
  version 14.40 or newer**, from Microsoft's official page:
  https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist
  (choose the X64 download, `vc_redist.x64.exe`). If it is missing or too old,
  `Start OfficeFlow.cmd` says so, opens that page and does not start.
  Installing it may need administrator rights.

The ZIP does not include any Microsoft runtime files.

## Get started

1. Extract the whole ZIP to a folder you keep, for example `Documents\OfficeFlow`.
2. Double-click **Start OfficeFlow.cmd**. Windows may warn that the file was
   downloaded from the internet; choose **Run** (or **More info → Run anyway**).
3. The first time, choose the administrator password (12–120 characters).
4. Your browser opens http://127.0.0.1:8080. Sign in as `001`.

Stop OfficeFlow with `Ctrl+C` in its window. `Quick Start.txt` in the ZIP covers
teachers, backups and common problems.

## Your data

The workspace is one file, `%LOCALAPPDATA%\OfficeFlow\officeflow.mv.db`, outside
the extracted folder. Updating means extracting the new ZIP to a new folder: it
opens the same workspace. Back up by copying that file while OfficeFlow is
stopped.

If you ran OfficeFlow from source before and your database is in a `data` folder
in the checkout, see "Upgrading from an earlier version" in the README.

## Highlights

- Supplies, teachers and requisitions with stock reservations: pending requests
  reserve stock, issuing deducts it once, and rejecting or cancelling releases it.
- Administrator and teacher accounts. New teachers get a one-time temporary
  password and choose their own at first sign-in.
- CSV import with rollback, and CSV reports.
- Clear startup messages for a busy port, a workspace already open, or missing files.

## Known limitations

- One PC only: other computers on the network cannot connect.
- The launcher and ZIP are not code-signed, so Windows SmartScreen may warn on
  first run.
- Organisations that block PowerShell scripts by policy will block the launcher.
- Stopping with `Ctrl+C` asks "Terminate batch job (Y/N)?"; either answer is fine.

## How this release was checked

Built and tested by the "Windows release package" workflow on a Windows Server
2025 runner, with system Java and Maven removed from `PATH`. The runtime is made
from the official Temurin JDK download after checking it against Adoptium's
published SHA-256. The source archive is checked against the same pinned build,
and Adoptium's source tarball is compared file by file with the exact OpenJDK
commit. The ZIP is checked to contain no Microsoft runtime files.

**Still pending:** the missing-runtime message has not yet been checked on a
clean Windows 10 or 11 PC without the Visual C++ Redistributable. The steps are
in `docs/releases/v1.0.0-clean-windows-test.md`. The test extracts
the ZIP into a folder with spaces, launches `Start OfficeFlow.cmd`, sets up the
administrator, adds a supply, restarts, and opens the same workspace from a
second extracted copy.
