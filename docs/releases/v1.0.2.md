# OfficeFlow 1.0.2

This update makes **Account** easier to find in the installed app: a bold label
and gear icon sit inside a visible button above the workspace. Account settings
still provide username, password, hint, recovery code and sign-out controls.
Your existing workspace and accounts remain in place when you upgrade.

## Windows security

This installer and its app are unsigned. Windows Smart App Control may block
setup, opening or uninstalling OfficeFlow. Microsoft Defender SmartScreen may
also display an unrecognized-app warning. GitHub hosting and SHA-256 checksums
do not establish a trusted publisher. Reliable operation with Smart App
Control On requires trusted code signing and a clean Windows 11 test. See
[Microsoft's Smart App Control FAQ](https://support.microsoft.com/en-gb/windows/security/threat-malware-protection/smart-app-control-frequently-asked-questions)
before deciding whether to change that protection; turning it off affects
other untrusted apps too.
