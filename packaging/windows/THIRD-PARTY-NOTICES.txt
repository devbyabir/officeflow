Microsoft Visual C++ runtime
----------------------------
Not included. The Microsoft Visual C++ runtime and Universal CRT files that
the Temurin JDK ships were removed from runtime\bin. OfficeFlow uses the
Microsoft Visual C++ Redistributable (x64) installed on the computer from
Microsoft, and the Universal CRT that is part of Windows 10 and 11.
